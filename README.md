# PIBIC 2026–2027

Repositório de acompanhamento das atividades do projeto PIBIC sobre **Social-RAG, Knowledge Graphs e análise de narrativas de negacionismo histórico em ecossistemas Telegram–YouTube**.

## Bolsistas

- **Jaime:** modelagem relacional e construção de Knowledge Graphs.
- **Edson:** curadoria de corpus e análise com Social-RAG.

## Organização do trabalho

As tarefas são registradas como Issues e acompanhadas no GitHub Project geral dos projetos PIBIC e PIBITI.

Toda tarefa deve indicar:

- responsável;
- objetivo;
- prazo;
- produto esperado;
- critério de conclusão;
- links para evidências, quando houver.

## Eixos do projeto

- formação em Zotero, Git/GitHub, Python, Elasticsearch e Hermes;
- revisão bibliográfica;
- curadoria de dados do Telegram e do YouTube;
- aplicação e avaliação do Social-RAG;
- modelagem de entidades e relações;
- construção e visualização de Knowledge Graphs;
- análise qualitativa;
- documentação, relatórios e artigos.
